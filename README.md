# Web Templates

A collection of responsive website templates built with plain HTML, CSS, and JavaScript. The repository currently contains a dental clinic landing page template and supporting assets.

## Overview

This project includes:

- A modern landing page for a dental healthcare brand
- Custom styling and layout for a professional service website
- Interactive JavaScript behavior for UI enhancements
- Image assets and template content for easy customization

## Project Structure

```text
Web-Templates/
├── Dental_Templete/
├── Img/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Files

- `index.html` — main page structure and content
- `style.css` — stylesheet for layout, typography, colors, and responsiveness
- `script.js` — interactive elements and page behavior
- `Img/` — image assets used in the template
- `Dental_Templete/` — additional template-related content

## Features

- Responsive design for desktop and mobile screens
- Clean, healthcare-focused visual style
- Simple static site setup with no build step required
- Easy to customize for branding, services, and contact details

## How to Run

Because this is a static website, you can open the project in a browser directly:

1. Clone the repository
2. Open `index.html` in your browser, or
3. Serve the folder with a local web server if you prefer

Example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

You can update the following to adapt the template to your own business:

- Text and headings in `index.html`
- Colors, spacing, and design in `style.css`
- Interactive behavior in `script.js`
- Images in the `Img/` folder
